

# arthas-demo
introduce el flujo de trabajo de arthas

- Instrumentación de bytecode JVMTI
- Estructura de archivos de clase Java
- Demo de ASM y bytekit, cómo funciona bytekit
- Flujo de arranque de arthas
- Cómo arthas maneja un comando, como el comando watch
- Proporciona soporte en arthas-core.jar y arthas-spy.jar para obtener la línea final y las variables locales mediante un rango de números de línea
